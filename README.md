# ryan1202.github.io

Personal site of **Jiajun Wang** — systems programmer, building [Horizon](https://github.com/Ryan1202/Horizon-Operating-System),
an x86_64 operating system in C and Rust.

Hand-written HTML, CSS and JavaScript. No frameworks, no build step, no trackers.

```
index.html            page content
assets/css/style.css  design system, dark/light themes, responsive layout
assets/js/main.js     theme toggle, terminal sequence, scroll reveal
assets/fonts/         Space Grotesk, Inter, JetBrains Mono (OFL, self-hosted)
assets/img/           avatar and social card
```

Local preview: `python3 -m http.server 8000` and open <http://localhost:8000>.

Typography: [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk),
[Inter](https://fonts.google.com/specimen/Inter) and
[JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono), all under the SIL Open Font License.
