Featured — operating system

Horizon

An experimental x86_64 operating system, written in C and Rust. Higher-half kernel, buddy allocator and SLUB, kernel threads, per-CPU data, interrupt handling, and a set of drivers — all booting from GRUB2 and running in QEMU.

Started in 2021 as a 32-bit toy kernel. Now migrating its core subsystems to Rust, one module at a time.

About

Jiajun Wang · Ryan1202
Ryan1202 · Suzhou

I'm Jiajun — Ryan to most people — a computer science student at Xi'an Jiaotong-Liverpool University.

Most of what I do happens below the application layer: page tables, interrupt controllers, schedulers, and the bugs that only appear when you boot your own code. Horizon started in 2021 as a 32-bit toy kernel; it is now a higher-half x86_64 kernel that boots from GRUB2 under QEMU, and it is slowly being rewritten in Rust module by module.

When I'm not in QEMU I write small tools to understand formats and machines from first principles — a JPEG decoder, an MP3 decoder, a red-black tree derived from 2-3-4 trees, a FAT image editor, a paging visualiser. Different layers, same question: how does this actually work?
