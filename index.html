Featured — operating system

Horizon

An experimental x86_64 operating system, written in C and Rust. Higher-half kernel, buddy allocator and SLUB, kernel threads, per-CPU data, interrupt handling, and a set of drivers — all booting from GRUB2 and running in QEMU.

Started in January 2020 as a 32-bit toy kernel and first uploaded to GitHub in July 2021. Now migrating its core subsystems to Rust, one module at a time.

About

Jiajun Wang · Ryan1202
Ryan1202 · Suzhou

I'm Jiajun — Ryan to most people — an undergraduate at Xi'an Jiaotong-Liverpool University, studying Data Science and Big Data Technology.

Officially that means statistics, AI and large-scale data. In practice I spend most of my time below the application layer: page tables, interrupt controllers, schedulers, and the bugs that only appear when you boot your own code. Horizon started in January 2020 as a 32-bit toy kernel and was first uploaded to GitHub in July 2021. It is now a higher-half x86_64 kernel that boots from GRUB2 under QEMU, and it is slowly being rewritten in Rust module by module.

When I'm not in QEMU I write small tools to understand formats and machines from first principles — a JPEG decoder, an MP3 decoder, a red-black tree derived from 2-3-4 trees, a disk-image editor. Different layers, same question: how does this actually work?
