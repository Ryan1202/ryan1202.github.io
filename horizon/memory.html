Boot

From GRUB to the higher half

GRUB hands boot information to Horizon through Multiboot2. The transition to long mode sets up the initial page tables, and early memory setup uses the boot memory map to distinguish usable physical ranges from reserved ones.

Frames

Physical memory and virtual mappings

The buddy allocator manages physical frames in power-of-two blocks. The page-table walker handles virtual mappings. Keeping these responsibilities separate lets vmalloc build a contiguous virtual range from physical pages that may be scattered.

Objects

Small allocations and C callers

SLUB-style caches supply small objects without dedicating a page to each one. Rust code can use the native memory interfaces, while C callers use the C ABI for allocations, mappings and caches.

DMA

Memory shared with devices

The DMA subsystem has a separate lifecycle for buffers used by devices. The June 2026 rewrite revised this subsystem after the memory and x86_64 changes.
