Threads, waits and context switches

The thread rewrite moved scheduling and yield logic into Rust. Wait queues give blocked threads a place to sleep until they can be woken. A thread that exits is cleaned up after the switch, when another thread is running.

Waking a thread during a switch

A wakeup can arrive while a blocked thread is still switching away. The wait queue marks it as waking. If it is still on a CPU, switch cleanup restores it to the run queue after the switch. Otherwise the waking code can queue it directly.
