Development history

Horizon

Horizon began as a 32-bit kernel in 2021. Its history runs from early experiments with booting and loading programs to a higher-half x86_64 kernel with core subsystems written in C and Rust.

Jul 2021

The first kernel

The initial commits established the project. Within the first week, a linker script gave the kernel an explicit link layout.

Linker script
Jul 2022

Loading programs

The tree gained an ELF loader, a test application and a system-call interface. Changes across the loader, paging code and process code brought executable loading into the kernel.

Application and ELF changes
Mar–Oct 2025

Storage work and the first Rust experiment

The FAT32 rewrite introduced partition discovery and block caching alongside a common object interface. Later that year, the build learned to link Rust code into the kernel as a static library.

Storage rework Rust static linking
Mar–Jul 2026

Memory, x86_64 and kernel threads

The memory rewrite introduced a layered allocator with Rust and C interfaces. The x86_64 port followed in April, then the summer thread rewrite moved scheduling and synchronization into Rust.

Memory rewrite x86_64 port Thread and synchronization rewrite
Aug–Nov 2026

From firmware tables to scheduler ticks

ACPI table discovery supplied interrupt-controller information. The IRQ core gained affinity support, and the timer work added periodic clock events from the PIT and the Local APIC timer.
