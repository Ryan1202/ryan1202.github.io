Boot

From GRUB to the higher half

GRUB hands boot information to Horizon through Multiboot2. The transition to long mode sets up the initial page tables, and early memory setup uses the boot memory map to distinguish usable physical ranges from reserved ones.

Early init

Reading the boot memory map

Early initialization reads the bootloader’s memory map to find usable physical ranges. It reserves the ranges occupied by the kernel and boot information before handing memory to the allocator.
